# AGL — Fonctionnalité 3 : les tâches

Statut : **validé par Bryan le 28/10/2026.**

## Idées du 26/10 (remplacées par les décisions ci-dessous)
- Lignes = groupes/projets, hiérarchiques ; colonnes À faire, En cours, Bloqué, Terminé.
- Sous-tâches en arbre ; groupe réservable à un agent (« Uniquement Max »).
- Carte : avancement, échéance, urgence si bloquée, « Voir le rapport ».
- À la création : « me prévenir à la fin », « rapport dans AGL » (Bryan répond, l'agent continue).
- Trois types : tâches, chantiers, automatisations (« réflexes »).

## Décisions
- Inspiration : Trello. Plusieurs **tableaux empilés** pour organiser.
- Un tableau = un nom + un émoji + un accès : tous les agents, ou les agents choisis (un seul pour les tâches de développement, par exemple).
- Colonnes de chaque tableau : À faire, En cours, Terminé, Bloqué.
- Carte : le titre (ex. « Lot 10 - Site Retux ») ; en cours, + une barre d'avancement estimé ; bloquée ou terminée, + « Voir le rapport » ; à faire, le titre seul.
- Survol d'une carte : une bordure apparaît ; clic au milieu : la carte s'agrandit avec tous les détails.
- Carte agrandie : titre, qui s'en occupe, date de création, échéance, étapes, journal ; lisible, aéré, ergonomique.
- Bloquée et échéance proche : notification d'urgence sur le téléphone.
- Pas de fil de discussion : seulement une réponse au rapport, dans un grand champ de texte.
- Qui la prend : par défaut n'importe quel agent ayant accès au tableau ; sinon Bryan choisit un ou plusieurs agents parmi eux, avec un ordre de priorité.
- Ordre : Bryan glisse les cartes verticalement dans une colonne (la plus haute = la plus urgente). Seuls les agents changent une carte de colonne.
- Pas de tâches personnelles de Bryan pour l'instant.
- Bloquée = il manque une info à l'agent, ou Bryan doit faire quelque chose à la main. Quand Bryan répond, une nouvelle carte repart dans À faire avec le même titre suivi de « #2 » (la suite), puis « #3 »…
- Plusieurs agents avec un ordre : le premier de la liste prend la carte s'il est libre, sinon le suivant.
- Création des cartes : par Bryan dans l'AGL (« + » en haut d'À faire), par Max quand Bryan le lui demande, par un agent qui délègue (s'il en a la permission). Champs : titre, consigne, échéance facultative, qui la fait (n'importe qui, ou agents choisis avec leur ordre).
- Notifications : seulement l'urgence (bloquée et échéance proche). C'est Max, l'assistant, qui prévient Bryan, personne d'autre.
- Aucun lien entre les tableaux et la carte du cerveau : c'est dissocié.
- Les cartes terminées restent 7 jours au maximum dans Terminé, puis sont archivées (consultables).
